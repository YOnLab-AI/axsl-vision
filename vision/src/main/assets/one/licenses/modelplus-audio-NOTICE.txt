Wenwu Wang, Mark D. Plumbley.

Original implementation: https://github.com/qiuqiangkong/audioset_tagging_cnn
Code revision: d2f4b8c18eab44737fcc0de1248ae21eb43f6aa4
Implementation license: MIT; see modelplus-panns-code-MIT.txt.

Changes by YOnLab: converted inference CNN6 and CNN10 tails to ONNX opset 17;
retained all trained network parameters; removed training-only dropout branches.
The model frontend is evaluated in Android Java at 32 kHz using the exact published
checkpoint's periodic Hann coefficients and mel filter weights. It performs centered
reflect-padded STFT (1024 FFT / 320 hop), power spectrum, 64-band mel projection,
and 10*log10(max(mel,1e-10)), matching the upstream parameters (50–14000 Hz).
The comparison workspace uses 0.975-second windows with 0.480-second steps.
The 527 output labels are copied from the upstream AudioSet class-label map.
Pinned checkpoint/code revisions, bytes, and model hashes are recorded in
one/modelplus/audio/audio-models.json.
